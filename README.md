## 🎯 Project Overview

This project simulates the work of a junior HR/Data Analyst.

The goal is to analyze employee information and create an HR analytics dashboard that can help answer questions about:

- Employee distribution
- Salaries
- Departments
- Performance
- Job satisfaction
- Overtime
- Employee attrition

The data used in this project is **synthetic/demo data created for educational purposes** and does not represent a real company's employees.

---

## 🏢 Business Problem

HR departments often have large amounts of employee information but need a simple way to understand what is happening across the organization.

This project aims to transform employee data into useful business information that could help HR investigate questions such as:

- Which department has the highest attrition?
- Which departments have the highest average salary?
- How common is overtime?
- Is lower job satisfaction associated with higher attrition?
- Are higher-performing employees paid more?
- Which departments have the most employees?
